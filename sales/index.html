Before you start

What does the Free package include?

The Mac terminal toolkit, source files, launcher, and setup guide. The source keeps its MIT license. The package does not include a BentoBoard license or an agent subscription.

Will it remove everything the agent suggests?

No. A supported local rule must approve the path. Uncommitted work, active files, and other protected data can block cleanup. Unsupported paths are inspect-only. No tool can promise that every deletion is safe.

Is this a native Mac app?

No. It is a Python terminal tool. This package does not bundle Python or provide a signed, notarized native installer. Windows cleanup is not supported.

Where does my disk report go?

Your chosen CLI uses its normal account and provider settings. Its provider can receive the prompt and tool results. DiskBoard adds no API proxy and does not upload reports itself.

Can I read the source?

Yes. View DiskBoard on GitHub. DiskBoard is free under the MIT license.
